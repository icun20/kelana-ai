# KelanaAI

AI Travel Planner — Trip Summary Generator (Console App)

## Deskripsi

KelanaAI adalah aplikasi perencanaan perjalanan berbasis AI. Pada versi awal ini, aplikasi menyediakan fitur **Trip Summary Generator** dalam bentuk aplikasi konsol Python yang menerima input dari pengguna dan menampilkan ringkasan perjalanan.

## Struktur Proyek

```
kelana-ai/
├── README.md
├── backend/
│   └── main.py
└── frontend/
    └── .gitkeep
```

## Cara Menjalankan

```bash
cd backend
python main.py
```

## Contoh Output

```
==============================
          KelanaAI

  Destination  : Japan
  Country      : Japan
```
